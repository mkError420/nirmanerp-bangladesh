# NirmanERP Bangladesh — Enterprise Construction & Real Estate Suite

NirmanERP Bangladesh is an enterprise-grade ERP solution tailored for civil engineering contractors, real estate developers, subcontracting managers, and financial accountants in Bangladesh.

---

## 🚀 Key Modules & Architecture

1. **Executive Directory & Project Profiles (Super Admin)**
   - Multi-project cost center registry with budget caps, land bank sizes (Katha), unit matrix, and project director allocations.
   - Super Admin project creation, budget editing, and active cost center switcher.

2. **Civil Engineering & Subcontracting**
   - Tower/Basement CPM Gantt schedules & staff allocations.
   - Master BoQ (CFT/SFT/Ton), Work Orders, and 10% Retention Fund management.
   - Site Daily Progress Reports (DPR) with photo attachments & site issue tracking.

3. **Stage-Gate Approvals & Workflow Chain**
   - Sequential 5-node department handoff: **Purchase → Store → Costing → Project → Accounts**.
   - Audit trail, digital sign-offs, and automated SMS alerts.

4. **Procurement & Site Store Inventory**
   - Material Requisitions (PR), 6-stage Purchase Orders (PO Engine), Goods Received Notes (GRN), and Gate Passes.
   - Material catalog with reorder points and regional price matrix.

5. **Human Capital & Payroll**
   - Employee HR directory & daily geotagged labor Hazira log.
   - Printable monthly salary sheets with automated tax & sign-off columns.
   - Bangladesh Bank BEFTN batch generation & bKash MFS disbursals.

6. **Financial Accounting & NBR Compliance**
   - Double-entry General Ledger (GL) & 3-way matching engine.
   - Real-time P&L Statement, Balance Sheet, and Maturing PDC Cheque tracking.
   - NBR Income Tax Act 2023 compliance (5% AIT withholding & TDS calculation).

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite, TailwindCSS, Lucide Icons.
- **Backend**: Node.js, Express, REST API.
- **Typography**: Merriweather, Lora, Cinzel & JetBrains Mono.

## 💻 Local Setup & Development

### Prerequisites
- Node.js (v18+ recommended)
- npm / yarn / pnpm

### Steps

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Assets**:
   ```bash
   npm run build
   ```
